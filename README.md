# american-zoo.com — новая версия

Статичный сайт повести Arlen Sunday «Американский зоопарк». Без сборки — открывается прямо из папки.

- `index.html` — главная
- `book.html` — оглавление всех 60 глав (открытые — ссылками, остальные «скоро»)
- `ch/*.html` — открытые главы
- `people.html` — архив «Требуют / предлагают / спрашивают» (2021)
- `about.html` — о проекте и об авторе

Тексты перенесены с american-zoo.com скриптом `tools/build_az.py`. Остальные главы на старом сайте закрыты регистрацией — добавим из рукописи.
